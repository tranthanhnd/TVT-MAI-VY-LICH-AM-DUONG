# T&T Mai Vy Tạo Lịch Âm Dương – v1.0.9

Tạo lịch âm dương Việt Nam theo năm (tên năm can chi tự đổi theo năm đang xem), ghép ảnh gia đình thành ảnh lịch 4K, và tạo ảnh Tết bằng AI (Gemini – cần API Key riêng của người dùng).

- Phần lịch chạy hoàn toàn trên trình duyệt, không cần mạng sau khi mở trang.
- Âm lịch tính bằng thư viện TT-AMLICH-VN do Minh Thành (T&T Hoàng Gia Royal) tự viết (công thức Meeus + bảng tiết khí, múi giờ UTC+7).
- Gemini API Key chỉ cần cho tính năng tạo ảnh AI; Key lưu trên máy người dùng.
- Khi Google đổi model hoặc Key hết hiệu lực, App sẽ hướng dẫn tạo API Key mới tại aistudio.google.com/apikey.

Bản cài Windows (.exe): tải ở mục [Releases](https://github.com/tranthanhnd/TVT-MAI-VY-LICH-AM-DUONG/releases/latest) (Setup hoặc Portable).
