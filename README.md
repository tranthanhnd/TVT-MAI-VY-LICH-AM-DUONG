# T&T Mai Vy Tạo Lịch Âm Dương – v1.0.13

Tạo lịch âm dương Việt Nam theo năm (tên năm can chi tự đổi theo năm đang xem), ghép ảnh gia đình thành ảnh lịch 4K, và tạo ảnh Tết bằng AI (Gemini – cần API Key riêng của người dùng).

- Phần lịch chạy hoàn toàn trên trình duyệt, không cần mạng sau khi mở trang.
- Âm lịch tính bằng thư viện TT-AMLICH-VN do Minh Thành (T&T Hoàng Gia Royal) tự viết (công thức Meeus + bảng tiết khí, múi giờ UTC+7).
- Lưu ý: lịch âm chỉ được bảo đảm đến khoảng năm 2050 (ngoại lệ năm 1967 nếu tính theo UTC+7); sau năm 2050 có thể lệch 1 ngày ở vài tháng do dự báo thiên văn chưa chắc chắn.
- Tạo ảnh bằng AI (Gemini, cần API Key riêng, lưu trên máy người dùng): 4 chức năng Tạo ảnh Tết, Cắt - Ghép ảnh, Thay trang phục, Thay bối cảnh; chọn mức chi phí theo mục đích; ảnh tạo ra dùng làm nền ảnh lịch. Có mục **Hướng dẫn sử dụng** ngay trong phần mềm.
- Đo độ giống khuôn mặt (FaceLock), Dán mặt gốc và Phóng to bằng máy chỉ có trong bản cài Windows; bản web vẫn tạo ảnh và làm lịch. AI vẽ lại ảnh nên không bảo đảm giống 100%: luôn soi mặt bằng mắt.
- Khi Google đổi model hoặc Key hết hiệu lực, App sẽ hướng dẫn tạo API Key mới tại aistudio.google.com/apikey.

Bản cài Windows (.exe): tải ở mục [Releases](https://github.com/tranthanhnd/TVT-MAI-VY-LICH-AM-DUONG/releases/latest) (Setup hoặc Portable).
